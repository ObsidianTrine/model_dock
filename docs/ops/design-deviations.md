# 设计偏差台账（design-deviations）

> 记录**超出概要设计原规划交付**或**设计定调后被反转 / 收敛**的能力。
> 用途：HLD（[../design/hld.md](../design/hld.md)）刷新、技术评审、验收对账时查「设计说了什么、实际做了什么」。
> HLD 本身设计先行、不载实施史；实施对账事实全部记在本页。新偏差随交付登记，条目只增不改（结论变化时新起一行并注明取代关系）。

## 反转与收敛（设计定调后改变方向）

| 能力 | 原设计口径 | 现状 | 定稿 |
|---|---|---|---|
| 用量统计与成本核算 | v1.1 概要设计定调「经评估不做」，占位命令指引看日志 | 全链上线：usage 聚合（日/小时桶、可计费口径、分模型时延）+ 成本折算（models.dev 牌价 + pricing.json 覆盖）+ 控制台今日用量徽标 | v1.6.0 反转上线 |
| anthropic ↔ openai 协议转换 | M3 规划的翻译层 | **定为不做**——以钉路由 / attach 前的协议兼容校验替代（不匹配拒绝并给修复路径），见 HLD ADR-13 | v1.7.2 收敛 |
| MCP 配置下发 / skill 分发 | 2026-10-29 产品决策前曾规划 phase 2 下发 | **不做**——MCP 只保留只读盘点（CLI + doctor 安检）；控制台盘点卡片亦下架 | v1.5.1 定调 / v1.5.2 下架卡片 |
